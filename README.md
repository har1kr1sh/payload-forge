# 🛠️ Payload Forge - Multi-Language Test Payload Generator

![Python 3.x](https://img.shields.io/badge/Python-3.x-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

**Payload Forge** is a lightweight, CLI-driven testing utility designed for **SOC Analysts, Detection Engineers, and Security Researchers**. It generates standardized, benign socket and execution scripts across multiple programming languages (PHP, Python, Ruby, C, PowerShell) for signature validation, YARA rule benchmarking, and EDR lab verification.

## 🎯 Purpose & Core Use Cases

Modern security teams need a quick, repeatable way to generate sample files in various programming languages to verify that their monitoring and prevention controls are functioning correctly.

* **YARA Rule Validation:** Instantly drop sample `.php`, `.py`, `.rb`, or `.c` files into a directory to test if your file-scanning rules flag common function signatures (e.g., `fsockopen`, `socket`, `system`).
* **EDR / AV Telemetry Benchmarking:** Test how endpoint detection agents log process creation and network socket initialization across different scripting runtimes.
* **Lab Emulation:** Quickly populate lab endpoints with benign test artifacts without having to manually write boilerplate code each time.

## 🚀 Quick Start & Usage

### Prerequisites
* Python 3.8 or higher installed.

### Command Line Interface

```bash
# Basic Syntax
python3 payload_generator.py -l <language> -i <target_ip> -p <target_port> -o <output_file>
```

### Examples

1. **Generate a safe PHP test script:**
   ```bash
   python3 payload_generator.py -l php -i 127.0.0.1 -p 4444 -o test_script.php
   ```

2. **Generate a safe C source file for compiler testing:**
   ```bash
   python3 payload_generator.py -l c -i 127.0.0.1 -p 8080 -o test_payload.c
   ```

3. **Generate a safe Python socket payload:**
   ```bash
   python3 payload_generator.py -l py -i 127.0.0.1 -p 9001 -o test_payload.py
   ```

| :--- | :--- | :--- | :--- |
